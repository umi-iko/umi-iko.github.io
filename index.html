サーフィン行こ

仲間と「いつ海に行くか」を共有するアプリです

  • 仲間の予定が見える誰がいつ海に行くかがカレンダーで分かるので、みんなが行くタイミングに合わせて海に行けます。
  • トリップの日程を合わせられる海外や船のトリップは、メンバー全員で行ける日を出し合って日程を決められます。
  • 仲間の動きを通知で知れるよく一緒に行く人が「海に行く」と登録したら、スマートフォンに通知が届きます。

使い方

見出しを押すと、その項目が開きます。

1このアプリでできること

「サーフィン行こ」は、仲間内で「いつ海に行くか」を共有するアプリです。できることは大きく3つです。

  • 仲間の予定が見える誰がいつ海に行くかがカレンダーで分かるので、みんなが行くタイミングに合わせて海に行けます。
  • トリップの日程を合わせられる海外や船のトリップは、メンバー全員で行ける日を出し合って日程を決められます。参加者限定の掲示板としおりも使えます。
  • 仲間の動きを通知で知れるよく一緒に行く人が「海に行く」と登録したら、スマートフォンに通知が届きます。誰の、どの予定を通知するかは自分で選べます。

利用は無料です。登録するのは名前とPIN(6桁の数字)だけで、電話番号やメールアドレスは使いません。

2ホーム画面に追加する(初回のみ)

ブラウザのブックマークではなく、ホーム画面のアイコンから開く形にしてください。アプリとして動作し、通知も受け取れるようになります。iPhoneでは、この手順を済ませないと通知が届きません。

iPhone(Safari)

  1. Safariで umi-iko.github.io を開く
  2. 画面下部(機種によっては上部)の共有ボタン(四角から矢印が上に出ているマーク)を押す
  3. メニューを下にスクロールし、「ホーム画面に追加」を押す
  4. 右上の「追加」を押す

Android(Chrome)

  1. Chromeで umi-iko.github.io を開く
  2. 右上の「⋮」を押す
  3. 「ホーム画面に追加」(または「アプリをインストール」)を押す

以後は、ホーム画面に追加された青い切手のアイコンから起動してください。

3登録とログイン

初回(まだ登録していない場合)

  1. 招待してくれた人から招待コードを受け取る
  2. ログイン画面の「招待コードで新しく登録する」を押す
  3. 招待コード、名前(ニックネーム可)、PIN(任意の6桁の数字)を入力し、「登録してはじめる」を押す

2回目以降

  1. 名前を入力して「次へ」
  2. PINの6桁を押す(6桁入力した時点で自動的にログインします)

一度ログインすれば、次回からは開くだけで使えます。PINを忘れた場合は、招待してくれた人(管理者)に再設定を依頼してください。

4行ける日を登録する
  1. 画面上部のタブで「海」「プール」「海外」のいずれかを選ぶ
  2. その下の丸いボタンから、自分の予定に合うものを1つ選ぶ
    • 行く … 行くと決めている(最も濃い色)
    • 誰か行こう … 誰か行くなら一緒に行きたい
    • ワンチャン … 状況次第で行けるかもしれない
  3. カレンダーの日付を指でなぞる(1日だけなら押すだけ)。色が付けば登録完了です

取り消す … 同じボタンを選んだまま、もう一度なぞると消えます。「🧽 消しゴム」を選んでなぞる方法でも構いません。

メモを付ける … 色を付けた日を長押し(1秒程度)すると、「朝一のみ」「○○ポイント希望」などのメモを残せます。メモは日付を押したときに仲間にも表示されます。

保存ボタンはありません。なぞった時点で保存されています。

5仲間の予定を見る
  • 日付の中の点(●)は、その日に予定を入れている仲間の人数です(1人につき1つ、10人を超えると「+n」)
  • 行き方のボタンを選んでいない状態で日付を押すと、誰がどの予定を入れているかが一覧で表示されます
  • カレンダーを左右にスワイプ(指で横に払う)すると、「海 → プール → 海外」とタブが切り替わります
  • 画面下の「仲間」を押すと仲間の一覧が開きます。名前を押すと、その人の予定とプロフィールが見られます
  • 名前に赤い丸が付いている人は、前回見たあとに新しく予定を入れています
6予定を見せる相手を選ぶ

自分の予定は、自分が「見せる」にした相手だけに表示されます。初期状態では誰にも見せていません。

  1. 画面下の「仲間」を押す
  2. 見せたい人の「見せる」にチェックを入れる(外せば非表示に戻ります)。全員に見せる場合は右上の「全員に見せる」

「見たい」のチェックは、その人の予定を自分のカレンダーに重ねて表示するかどうかの設定です。相手が自分に「見せる」にしていない場合はチェックできません。

7トリップの日程調整

トリップを作る(発起人)

  1. 上部タブの右端「＋追加」を押す
  2. 名前(例: バリ 11月)を入力し、種類と参加者を選んで「作る」

日程を合わせる(参加者全員)

  1. 上部タブに追加されたトリップ名を押す
  2. 通常のカレンダーと同じ要領で、行ける / 要調整 / 行けないを選んで日付をなぞる
  3. 全員が「行ける」の日は、上の要約欄に★付きで表示されます

日程が決まったら … 発起人が「日程を選んで確定する」を押します。確定すると参加者限定のトリップページが開けるようになり、しおり(集合場所・持ち物などのメモ。参加者なら誰でも編集可)と掲示板が使えます。

8ボートトリップの募集に回答する

定員のあるボートトリップで空きが出た場合、声をかけられた人の上部タブに「📣 (トリップ名)」が表示されます。

  1. そのタブを押すと、日程・案内文(料金や集合場所など)が確認できます
  2. 「行く」「前向きに検討」「様子見」「行けない」のいずれかを押します。締切までは何度でも変更できます
  3. 締切後、主催者が参加者を決定します。参加が確定すると通知が届き、トリップページに入れるようになります

「行く」と回答しても、定員の関係でキャンセル待ちになる場合があります。

9サーフィンした日数の記録

「行く」にしていた日は、日付が過ぎると自動的に「行った」として集計されます。

  • 画面下の「自分」に、今年と累計の日数が表示されます。その下に仲間全員の行った日数ランキング(今年 / 累計)も出ます
  • 実際には行かなかった日 … 「🧽 消しゴム」を選び、過去のその日をなぞると記録から外れます
  • 予定に入れていなかったが行った日 … 「✓ 行った」を選び、過去のその日をなぞると記録に加わります
10通知を受け取る

仲間が予定を入れたときや、トリップの連絡があったときに、スマートフォンに通知が届き、アイコンに件数が表示されます。

  1. ホーム画面のアイコンからアプリを開く(項目2を参照。iPhoneでは必須です)
  2. 画面下の「自分」→「🔔 通知」の「この端末で通知をオンにする」を押す
  3. 「通知を許可しますか」と表示されたら「許可」を選ぶ
  4. 「テスト通知を送る」を押し、1分以内に届くことを確認する

設定の調整 … 「控えめ」は音を鳴らさず通知を1件にまとめます。「しっかり」は毎回通知します。どの予定を通知するか(例: 海の「行く」だけ、特定の人だけ、何日先まで)は、同じ画面の「ルール」で細かく決められます。

届かない場合は、スマートフォンの「設定」→「通知」で、このアプリの通知が許可されているか確認してください。

11困ったとき
  • PINを忘れた … 招待してくれた人(管理者)に再設定を依頼してください
  • 表示が古い、動作がおかしい … アプリを一度完全に閉じて、開き直してください
  • なぞっても色が付かない … 行き方のボタン(行く / 誰か行こう / ワンチャン)が選ばれているか確認してください。未選択のときは閲覧モードです。過去の日付には予定を入れられません
  • 仲間の予定が見えない … 相手があなたに「見せる」の設定をしていないと表示されません
  • 誤って登録した … 同じボタンでもう一度なぞれば取り消せます

解決しない場合は、招待してくれた人に相談してください。
